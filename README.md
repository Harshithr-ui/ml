# Machine Learning Projects

A collection of machine learning projects and applications.

## Projects

### 🌸 [Iris Flower Classifier](./iris-classifier)
An end-to-end Machine Learning web application built with Python, scikit-learn, and Flask that predicts the Iris flower species (*Setosa*, *Versicolor*, or *Virginica*) given sepal and petal dimensions.

- **Stack**: Python, Scikit-learn, Flask, HTML/CSS
- **Details**: Full pipeline covering data exploration, model training, evaluation, persistence, and web deployment.
- **Directory**: [`iris-classifier/`](./iris-classifier)
